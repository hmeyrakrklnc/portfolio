- **Hakkımda:** İlgi alanlarım ve profesyonel yaklaşımım

## Kullanılan teknolojiler

Portföy sitesi **HTML, CSS ve JavaScript** ile hazırlanmıştır.
Responsive tasarımı sayesinde masaüstü ve mobil cihazlara uyum sağlar.
